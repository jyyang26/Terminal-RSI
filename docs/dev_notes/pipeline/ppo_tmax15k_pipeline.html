🔁 异步主循环 (train_async.py)：gen(rollout_id+1) 在训练 rollout_id 之前发起 → SGLang 采样与 Megatron 训练并行重叠。num_rollout=100，每步同步权重。
① Rollout 采样 SGLang · 40 GPU
从 tmax-15k 池取 260 个 task（oversample），每个 = 1 Daytona sandbox + 1 Terminus2 agent 串行多轮 loop；收前 256 个完成的（skim），丢慢尾。
5 × TP8 引擎 · trajectory_retokenized → Sample(tokens, loss_mask, reward, rollout_log_probs, group_id)
trajectories + reward + rollout_log_probs
② Data Buffer Ray object
RolloutDataSource 汇聚 Sample，做 skim-oversample、token-cap postprocess（>64k 截断）、group_mask_sums 预计算，供训练侧按 group 读取。
rollout_batch_size=256 · over_sampling=260 · n_samples_per_prompt=1
rollout_data (batch)
③ Critic 训练 Megatron · 16 GPU
冷启动 value head（重初始化）。前向算 value → GAE 得 advantage/return → 反向最小化 value 的 clipped MSE。产出 values 供 actor。
critic_lr = 1.5e-5 (30×) · value_clip=0.2 · 与 actor 复用同一 placement group
⏳ num_critic_only_steps=2：rollout_id 0、1 只训 critic（actor 不更新），让 value 预热到正确尺度，避免乱 value 毁 actor。step≥2 起 actor 才加入。
values (external_data) · advantages
④ Actor 训练 Megatron · 16 GPU · step≥2
重算 log_probs → PPO ratio·advantage 的 clipped 目标 → 反向。KL off、entropy off。可选记录 train/inference 失配指标（tis / tis_abs）。
actor_lr = 1e-6 (2×) · eps_clip=0.2 · grad_clip=1.0 · loss = pg_loss
updated actor weights (NCCL)
⑤ Weight Sync 每步
actor 新权重经 NCCL 组推给 5 个 SGLang 引擎（PP8 → 多次分段 Update weights），保证下一轮 rollout 用最新策略（近 on-policy）。
update_weights_interval=1 → 回到 ①
↺ 回到 ① Rollout（下一 rollout_id）
📊 周期动作：每 save_interval=5 存 checkpoint；每 eval_interval=10 跑 Terminal-Bench 2.0 全 89 题 × n=3 eval（temp 1.0 / top-p 0.95 / top-k 20），headline = harbor/eval_resolved_rate_full (avg@3)。
